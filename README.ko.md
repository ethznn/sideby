# Sideby

작업은 갈아타고. 화면은 따라오고.

[홈페이지](https://ethznn.github.io/sideby/ko/) · [English](README.md)

Sideby는 함께 쓰는 macOS Space를 연결해, 여러 모니터를 다음 작업으로 한 번에 전환합니다. 같은 데스크탑의 서로 다른 창 배치를 저장하고, 큰 화면 미리보기에서 돌아갈 작업을 고를 수 있습니다.

**배포 준비 중입니다.** 앱의 공개 다운로드를 잠시 중단했습니다. 배포가 준비되면 홈페이지에서 안내하겠습니다.

## 주요 기능

- 여러 모니터의 연결된 Space를 함께 전환합니다.
- 같은 일반 데스크탑에 창 위치와 크기가 다른 구성을 저장합니다.
- **⌥⇧Space**로 갤러리를 열어 작업 화면을 고릅니다.
- 메뉴 막대에서 Space 연결을 편집합니다.

macOS 14 이상을 사용하는 Apple Silicon Mac을 지원합니다. 창 배치는 이동한 데스크탑에 남아 있는 저장된 창을 대상으로 복원합니다. 앱·문서·탭을 다시 열거나 다른 Space의 창을 가져오지는 않습니다. 전체 화면 앱은 Space만 전환합니다. 창 배치 복원은 Stage Manager를 끈 상태를 지원하며 앱의 창 크기 제한에 영향을 받을 수 있습니다.

## 개인정보와 권한 안내

전역 입력과 창 배치 복원에 손쉬운 사용, Space 이동에 화면 전환 접근을 사용합니다. 일부 전환에는 System Events 자동화도 필요합니다. 화면 기록은 미리보기를 허용할 때 요청하는 선택 권한입니다.

일반 미리보기는 메모리에만 보관합니다. 직접 저장한 구성의 이미지와 창 정보는 Mac에 보관하며, 미리보기를 꺼도 저장된 구성의 이미지는 남습니다. 이미지나 입력 내용을 서버로 보내지 않습니다.

## 이 저장소

이 저장소에는 제품 소개 사이트가 있으며 앱 소스와 설치 파일은 포함하지 않습니다. 저장소의 MIT 라이선스는 이 사이트의 소스에 적용됩니다. 로컬 빌드와 확인 방법은 [홈페이지 관리 문서](docs/WEBSITE.md)를 참고하세요.
