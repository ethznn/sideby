## 한 화면에서 보고 바로 연결하세요

<p align="center">
  <img src="./docs/images/sideby-connections-settings-ko.png" width="880" alt="실제 설정 창 위쪽의 모니터별 Space 목록과 아래쪽의 연결표. 같은 모니터의 칸끼리 이동·복사할 수 있습니다." />
</p>

*가상 데이터를 넣은 실제 앱 화면입니다.*

1. **메뉴 막대의 Sideby → 설정**을 여세요. ‘Space 연결’이 바로 열립니다.
2. **위쪽에서 각 Space의 내용을 확인하세요.** 읽을 수 있는 앱·창 제목과 Space 순서, 모니터별 총 개수, ‘지금 보고 있음’ 표시가 나옵니다.
3. **위 카드를 아래 같은 모니터의 빈 칸으로 끌어 놓으세요.** 첫 연결부터 바로 만들 수 있고, 카드를 선택한 뒤 칸을 눌러도 됩니다. 변경은 즉시 기억되며 **되돌리기** 또는 `⌘Z`로 최근 20단계까지 차례로 되돌립니다. 앱을 다시 열어도 복구 기록이 유지됩니다.

같은 열의 Space들이 함께 전환됩니다. 칸을 눌러 직접 선택할 수도 있습니다.

- **새 연결:** 오른쪽 **연결 추가** 열의 빈 칸에 첫 Space를 놓으면 연결이 생깁니다. 다른 모니터의 Space도 **같은 열의 해당 모니터 행**에 놓으세요. + 버튼은 새 연결을 만들 빈 열로 이동합니다.
- **이동·자리 바꾸기:** 같은 모니터의 칸끼리 드래그하세요. 빈 칸으로 옮기거나, 채워진 두 칸의 자리를 바꿉니다.
- **복사:** **⌥ Option을 누른 채 놓으면** 원본 칸을 유지합니다. 위쪽 Space 목록에서 가져올 때도 목록은 그대로입니다.
- **실수 복구:** **되돌리기** 한 번으로 두 칸을 함께 복구합니다.

한 칸만 비우려면 칸을 누르고 **이 칸 연결 해제**를 선택하세요. 모니터 이름 옆 **… → 이 모니터의 연결 비우기…**로 해당 행만 정리할 수 있습니다. 연결 해제된 모니터의 정보도 정리할 수 있으며 다른 모니터의 연결은 유지됩니다. 열 제목의 **…** 또는 우클릭 메뉴에서는 열을 지우거나 순서를 바꿉니다.

여러 열을 함께 지우려면 연결표 왼쪽 위의 **여러 연결 선택**을 누르세요. 열 제목이나 칸을 눌러 선택하고 **선택한 N개 삭제…**로 확인합니다. 하나만 선택했다면 확인창 없이 바로 삭제합니다. **전체 선택**도 가능하며, **선택 취소**는 연결을 바꾸지 않고 선택 모드를 닫습니다. 선택한 열은 **되돌리기** 한 번으로 함께 복구됩니다. 선택 중에는 칸 편집이나 화면 이동이 일어나지 않습니다.

처음부터 다시 연결하려면 **연결 모두 비우기…**를 누르고 확인하세요. 연결 해제된 모니터의 연결도 함께 비우며, 실제 Space와 열린 앱은 그대로 유지됩니다. 비운 뒤에도 빈 칸이 남아 바로 새 연결을 만들 수 있습니다. 다시 설정하다가 이전 상태로 돌아가려면 **되돌리기**를 차례로 누르세요. 최근 20단계의 연결 변경에 전체 비우기도 포함됩니다.

실제 화면을 이동하려면 열 제목 아래 **함께 이동**을 누르세요. 채워진 카드는 연결된 Space이고, 점선 **+** 칸은 새로 연결할 자리입니다. **연결 추가**를 누르면 빈 열이 나타나며, **…** 메뉴에서 연결 순서를 바꾸거나 삭제할 수 있습니다. 칸 편집과 드래그는 화면을 이동하지 않습니다. 전환에서 제외한 화면은 연결을 바꾸어도 움직이지 않습니다.

## 처음 시작하기

1. [GitHub Releases](https://github.com/ethznn/sideby/releases)에서 DMG를 내려받아 Sideby를 응용 프로그램으로 옮깁니다.
2. 첫 사용 안내에서 손쉬운 사용과 화면 전환 접근을 허용합니다.
3. 빈 칸에서 Space를 골라 연결하세요. **순서대로 연결**하면 선택한 모니터의 Space를 같은 순서끼리 한 번에 연결할 수도 있습니다. 별도 이름 입력이나 저장, 전환 연습은 필수가 아닙니다.

이전 버전의 연결·이름·숫자 단축키는 유지됩니다. 다시 만들거나 삭제할 필요가 없습니다. 기존 창에 저장하지 않은 편집이 있다면 먼저 그 편집을 마무리하도록 안내합니다.

## 일상에서는 빠르게

**⌥⇧Space**를 누르고 있으면 포인터 가까이에 빠른 이동 화면이 열립니다. 위쪽의 **원형·표**로 보기를 바꿀 수 있으며, 전환 버튼 위치는 유지되고 마지막으로 고른 보기를 기억합니다. 연결을 누르면 해당 Space들로 함께 이동합니다. 원형 메뉴는 화면 밖으로 나가지 않고, 사각 배경 없이 원과 칸 사이가 투명하게 보입니다. 연결은 한 페이지에 최대 8개씩 표시됩니다.

원형 메뉴에서 연결을 드래그하면 순서를 바꿀 수 있습니다. 연결된 Space와 숫자 단축키는 유지되며, 실제 화면은 이동하지 않습니다. **되돌리기**로 이전 순서를 복구할 수 있습니다.

연결에 포인터를 올리면 가운데에서 연결된 Space의 내용을 미리 봅니다. 가운데에 포인터를 올리면 **현재 상태 추가하기**가 나타나며, 누르면 지금 보고 있는 Space들을 하나의 연결로 묶습니다. 이름은 **Xcode / Figma**처럼 자동으로 붙이며, 같은 연결이 있으면 중복으로 만들지 않고 보여 줍니다. 연결이 하나도 없을 때도 가운데에서 안내를 따라 첫 연결을 만들 수 있습니다.

모니터가 3대 이상이면 가운데 원을 넓혀 연결된 각 모니터의 내용을 보여 줍니다. 연결 사이를 오갈 때 메뉴 크기는 유지되며, 화면 공간이 부족하면 표 보기로 열립니다. 아주 짧은 전환에는 연결 이름 HUD를 생략하고, 표시할 때는 부드럽게 나타나고 사라집니다.

*28초 사용법: 드래그로 연결 → 현재 화면으로 연결 → 개발 중 단축키 이동 → 자리 바꾸기·되돌리기·Option 복사·이름 수정 → 이동과 복귀 → 삭제와 복구. Sideby 1.1.0 UI와 가상 데이터로 재구성했습니다. 현재 앱에는 위에서 설명한 가운데 호버 미리보기, 원형·표 전환, 원형 메뉴의 순서 변경도 포함되어 있습니다.*

[재생·정지하며 보기](https://ethznn.github.io/sideby/ko/#tutorial) · [정지 이미지](docs/images/sideby-tutorial-ko.png)

연결에 포인터를 올리면 **연필**과 **휴지통**이 나타납니다. 이름과 칸을 누르면 이동하고, 연필만 이름을 수정합니다. **적용**하면 이름을 바꾸고 **취소**하면 유지하며, 적용한 뒤에도 **되돌리기**로 복구합니다. 연결 하나는 확인창 없이 바로 삭제합니다. 실제 Space와 열린 앱은 유지되며, 항상 보이는 **되돌리기**로 연결·배정·단축키를 함께 복구합니다. 마지막 연결을 지우거나 앱을 다시 열어도 복구할 수 있습니다.

**연결 편집**을 누르면 모니터별 Space 목록과 연결표를 봅니다. 같은 모니터의 칸끼리 드래그하면 이동하거나 자리를 바꾸고, Option을 누른 채 놓으면 복사합니다. 편집 중에는 원형·표 버튼이 숨겨지며, **이동 화면으로**를 누르면 이전 보기로 돌아옵니다. **모두 비우기…**는 확인 후 전체 연결을 비우며, 비운 뒤에도 가운데에서 바로 첫 연결을 만들 수 있습니다.

| 조작 | 결과 |
| --- | --- |
| `⌥⇧Space` 누르고 있기 | 포인터 가까이에 마지막으로 사용한 원형 또는 표 보기를 엽니다. 연결을 눌러 함께 이동합니다. |
| `⌥⇧Tab` | 직전에 이동한 연결로 돌아갑니다. |
| `⌥⇧1` … `⌥⇧9`, `⌥⇧0` | 해당 숫자가 배정된 연결로 이동합니다. 다른 연결을 지워도 기존 번호는 유지됩니다. |
| `⌥⇧<` / `⌥⇧>` | 이전 / 다음 연결로 이동합니다. |
| Option + Shift + 가로 스와이프 | 기본 제스처로 함께 전환합니다. |

숫자·이전/다음·복귀 단축키는 Option과 Shift를 놓을 때 실행됩니다. 빠른 이동 화면은 여는 단축키를 놓으면 닫히며, 키를 놓는 동작만으로 저장하거나 이동하지 않습니다. 보기 전환·순서 변경·저장·이름 수정·삭제·편집을 시작하면 창이 유지됩니다. 단축키를 놓고 편집하다가 Space를 복사할 때 Option을 다시 누르세요. Tab으로 버튼에 이동하고 Return/Space로 실행하며, Escape로 닫을 수 있습니다. **설정 → 입력**에서 조작 방식을 바꿉니다.

## 환경이 바뀌었을 때

데스크탑 순서가 바뀌어도 같은 데스크탑의 연결을 따라갑니다. 없어졌다면 그 칸에 **다시 선택**을 표시하며, 같은 번호의 다른 데스크탑으로 임의 연결하지 않습니다. 추가된 데스크탑은 위 목록에서 찾아 필요한 칸에 연결하세요. 모니터 연결을 빼도 해당 연결은 유지되며 **연결 해제된 모니터 보기**로 확인할 수 있습니다.

앱에서 **Space**는 일반 데스크탑과 전체 화면 앱을 포함하는 macOS 작업 공간이며, **모니터**와 구분합니다. **3번째 Space**는 해당 모니터 목록에서의 순서이며, Mission Control의 실제 이름인 ‘데스크탑 3’을 뜻하지 않습니다. 읽을 수 있는 앱·창 이름을 우선 표시합니다.

빠른 전환 메뉴의 **연결 수정**에서도 연결을 비우고 다시 만들 때 제목, Space 목록과 드롭 칸의 위치를 유지합니다. Space 선택 목록은 화면 안에 표시됩니다. 저장한 Space가 없으면 **Space 다시 선택**으로 다른 Space를 고르거나 **이 칸 연결 해제**를 누르세요. 같은 모니터의 다른 칸을 Option 드래그해 복사할 수도 있고, 변경은 되돌릴 수 있습니다.

연결 편집 화면이 보이는 동안 Space 목록과 읽을 수 있는 앱·창 제목을 자동으로 갱신합니다. Space를 읽지 못했을 때는 모니터 연결을 확인한 뒤 **다시 읽기**를 누르세요. 직접 지정한 데스크탑 이름이 있으면 우선 표시합니다. 이 이름은 macOS Mission Control의 이름을 바꾸지 않습니다. 설정을 기록하지 못하면 기존 연결을 유지하고 실패를 알립니다.

Sideby는 기존 Spaces를 연결하고 전환합니다. 데스크탑을 만들거나 지우고, 앱을 실행하거나 전체 화면으로 만들고, 창 위치를 복원하는 기능은 제공하지 않습니다.

## 개인정보와 플랫폼 안내

설정한 전역 제스처와 가능한 앱·창 제목 제안을 위해 손쉬운 사용 권한을 사용합니다. 화면 전환 접근 권한으로 요청한 데스크탑 이동을 실행하며 일부 경로에는 System Events 자동화 권한도 필요합니다. 전환과 데스크탑 조회를 위해 화면 기록 권한을 요청하지 않습니다.

구성 이름, 데스크탑 연결 정보, 직접 정한 데스크탑 이름, 화면 선택, 단축키 배정, 되돌리기 데이터, 이전 설정 백업, 입력 설정, 안내 진행 상태는 Mac에 로컬로 저장합니다. 실행 중 사용하는 숫자 Space ID·창 ID, 원시 입력 이벤트, 스크린샷은 저장하지 않습니다. 전역 단축키 처리 중 입력한 글자를 기록하지 않습니다.

직접 배포 앱으로, App Sandbox를 끈 상태에서 비공개 SkyLight API를 사용합니다. 업데이트에는 Sparkle 2를 사용하며 설치는 사용자가 승인합니다. 업데이트 창은 앱에서 선택한 언어를 따르며, 언어를 바꾼 경우 Sideby를 다시 열면 적용됩니다. 릴리즈 노트는 영어로 제공합니다.

## 개발

Swift 6 도구 모음으로 Xcode에서 `Package.swift`를 열거나 아래 명령을 실행하세요.

```bash
swift test
swift build --product SidebyApp
swift build --product SidebyDevApp
```

`SidebyApp`은 제품 앱이며 `SidebyDevApp`은 로컬 점검 도구입니다. 로컬 앱 번들을 만들기 전 [Sparkle 피드](https://github.com/ethznn/sideby/releases/latest/download/appcast.xml)의 최신 `sparkle:version`을 확인하고, 여기에 1을 더한 값을 `SIDEBY_BUILD_NUMBER`로 지정해 `scripts/build_app_bundle.sh`를 실행하세요.

[개발 안내](docs/DEVELOPMENT.md), [결정 기록](docs/DECISIONS.md), [README 미디어](docs/media/README.md)를 참고하세요. 문서의 실제 앱 화면은 분리된 샘플 데이터로 만듭니다. GIF와 정지 이미지는 저장소에, 전체 MP4는 로컬에 보관합니다.
