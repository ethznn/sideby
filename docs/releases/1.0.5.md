# Sideby 1.0.5

**Remove a connection without leaving the quick matrix.**

- Open **⌥⇧Space**, then choose a connection’s **⋯ → Remove connection · Keep Spaces** menu. There is no need to enter Edit connections.
- The actual Spaces and app windows stay open. Only the saved connection is removed.
- Use **Undo** in the same panel to restore the connection, its Space assignments, and its numbered shortcut. This also works after removing the current or last connection.
- Opening the action menu keeps the panel open when you release the shortcut. Cancelling the menu leaves connections unchanged. Connection actions are disabled while switching.

The English and Korean README and website now explain direct removal and recovery. Existing connection names, assignments, and shortcuts are preserved when updating.

**Update:** choose **Settings → General → Check for Updates**, or open the DMG and drag Sideby to Applications. Requires Apple silicon and macOS 14 or later.
