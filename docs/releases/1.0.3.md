# Sideby 1.0.3

**Keep the Spaces you are looking at together, straight from the shortcut window.**

- **Connect current Spaces:** open the switcher with **⌥⇧Space** and choose **Connect current Spaces**. Sideby adds the currently visible Space on each participating display as one connection, without moving your screens or opening a separate save window. The new column comes into view and can be undone immediately. If the same connection already exists, Sideby shows it instead of creating a duplicate.
- **Recognizable default names:** new connections made from current Spaces use names such as **Xcode / Figma**, in display-row order. Custom Space names take priority; unavailable titles fall back to their Space positions. Long names keep a part from each display. Later window-title changes do not rename an existing connection.
- **Rename in place:** choose **Edit connections**, then click a column's name or pencil to rename it in the same window. You can also use **Rename connection** from the column menu. Apply or cancel the edit, and use **Undo** to restore the previous name. This also works in Settings.
- **Clearer editing feedback:** long connection names have more room in column headers, and the shortcut editor brings the result and Undo into view after a change.
- **Preserve your work:** adding a connection requires readable Space identities for every participating connected display. Renaming keeps all Space assignments and shortcuts. Failed writes and conflicting name edits preserve existing data.

The English and Korean README and website now show the restored shortcut action and name editing. Existing connections, custom names, shortcuts, and undo history are preserved.

**Update:** choose **Settings → General → Check for Updates**, or open the DMG and drag Sideby to Applications. Requires Apple silicon and macOS 14 or later.
