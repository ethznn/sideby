# Sideby 0.13.0

## 한국어

지금 쓰는 화면 구성을 저장하고, 필요할 때 다시 고르세요.

- `⌥⇧Space`로 연 매트릭스에서 **이 구성 저장**을 선택할 수 있습니다. 키를 놓은 뒤 이름과 포함할 화면을 확인하면 구성 하나가 추가됩니다.
- 새 설치는 빈 목록에서 시작합니다. 데스크탑 추가나 상태 확인이 구성을 자동 생성하거나 기존 구성을 덮어쓰지 않습니다.
- 구성별 **편집**에서 이름과 데스크탑 연결을 바꾸고, 변경 내용을 확인한 뒤 저장합니다. 동일한 구성은 중복 저장을 막습니다.
- **최근 변경 되돌리기**로 마지막 추가·수정·삭제를 복구할 수 있습니다. 앱을 다시 열어도 다음 구성 변경 전까지 유지합니다.
- 매트릭스에서 **저장한 구성 모두 삭제…**를 지원합니다. 확인 후 저장한 구성만 비우고 실제 데스크탑·앱·다른 설정은 유지합니다. 전체 삭제도 되돌릴 수 있습니다.
- 매트릭스에는 현재 연결된 화면만 표시합니다. 연결되지 않은 모니터의 저장 정보는 구성 편집에 남겨 재연결 시 사용할 수 있습니다.
- 저장한 구성을 삭제해도 다른 구성의 숫자 단축키는 바뀌지 않습니다. 데스크탑 순서가 바뀌면 저장된 연결이 같은 데스크탑을 따라갑니다.
- 메뉴·매트릭스·설정·첫 사용 안내를 현재 구성 저장 흐름에 맞췄습니다. 화면은 시스템 라이트·다크 모드를 따릅니다.
- 한국어·영어 README, 실제 앱 화면을 사용한 스크린샷, 사용 흐름 미리보기를 새로 정리했습니다.

### 업데이트 후 기존 구성이 보인다면

이전 버전의 구성은 모두 보존합니다. 과거에 자동 생성된 구성도 포함되며, 이번 버전이 새로 만든 항목은 아닙니다. 직접 저장한 구성만으로 시작하려면 **저장한 구성 모두 삭제…**를 실행하고 현재 구성을 저장하세요. 다음 구성 변경 전까지 **최근 변경 되돌리기**로 원래 목록을 복구할 수 있습니다.

Sideby는 기존 데스크탑의 연결을 기억합니다. 앱·문서·창 위치를 복원하거나 스크린샷을 저장하지 않습니다. 처음 설치할 때 필요한 권한을 허용하고, 업데이트는 Sideby의 업데이트 확인 또는 GitHub Releases를 이용하세요.

## English

Save the desktop setup you're using, then choose it when you need it again.

- Choose **Save this setup** from the matrix opened with `⌥⇧Space`. Release the keys, enter a name, select the displays to remember, and add one setup.
- Fresh installations start with an empty list. Adding desktops or checking their status does not generate setups or replace your saved setup.
- **Edit** a setup’s name and desktop connections, review the changes, and save. Identical setups are caught before a duplicate is added.
- **Undo last change** restores the most recent addition, edit, or deletion, including across app restarts until the next setup change.
- **Delete all saved setups…** clears the saved list after confirmation. Desktops, apps, and other settings remain. This action can also be undone.
- The matrix shows only currently connected displays. Connections for disconnected monitors remain in setup editing and are available on reconnection.
- Deleting one setup keeps the other setups’ numbered shortcuts stable. Saved connections follow the same desktops when their order changes.
- Menus, the matrix, settings, and onboarding now follow the save-current-setup flow, with an interface that follows system light and dark appearance.
- English and Korean READMEs, production-view screenshots, and the workflow preview have been refreshed.

### Existing setups after upgrading

All previous setups are preserved, including entries that older versions created automatically. These are not newly generated by 0.13.0. To start with only the setups you choose to save, select **Delete all saved setups…**, then save your current setup. **Undo last change** can restore the original list until your next setup change.

Sideby remembers connections to existing desktops. It does not restore apps, documents, or window positions, and does not save screenshots. Allow the required permissions on first installation. Update using Sideby’s update check or GitHub Releases.
