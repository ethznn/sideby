# Sideby 0.12.0

Released September 26, 2026 · 2026년 9월 26일

## English

Give each desktop a name you recognize, and choose your next task without leaving the keyboard shortcut behind.

- **Name individual desktops.** Open a matrix cell’s menu and choose **Rename desktop…**. The name belongs to that desktop, so using it in several workspaces shows the same name everywhere. Your names survive reordering, app restarts, display reconnection, and **Rebuild from current desktops…**. Choose **Use automatic name** to return to app/window content suggestions. These names appear in Sideby; Mission Control names stay unchanged.
- **Hold a shortcut to choose a task.** Hold **⌥⇧Space** to show the quick matrix near your pointer, then click a workspace column to switch. You can switch again while holding the keys. Release the shortcut or press Escape to close it. Change or disable this shortcut in **Settings → Input**.
- **Keep the menu open while switching.** The menu bar matrix stays in place after a move, preserving its size and scroll position. Switching no longer brings up the full Settings window. This also addresses a macOS 27 issue where a visible matrix could stop accepting clicks after a desktop change.
- **Read and edit the matrix more easily.** Clearer light and dark surfaces distinguish the current workspace, desktop assignments, and drop targets. The Go button lines up with the workspace name, with a separate Current label. The menu, Settings, and onboarding use consistent surfaces and controls.
- **Undo a rebuild where it happens.** The completion message offers **Undo** immediately after rebuilding. The permanent restore button has been removed from the everyday interface.

Existing workspace assignments, names, and input settings are retained. Custom desktop names and the quick-matrix preference are stored locally on your Mac. Workspace names and desktop names are separate: renaming a desktop does not silently rename an existing workspace. Sideby still works with one display and does not create, delete, or rename macOS Spaces.

The English and Korean READMEs include refreshed native screenshots, a short illustrated loop, and links to the 21-second brand film in landscape and vertical formats. The film uses actual Sideby views with sample data and illustrated desktops; The films include an original score and are available as release attachments. Requires macOS 14 or later.

## 한국어

각 데스크탑에 알아보기 쉬운 이름을 붙이고, 단축키를 누른 채 다음 작업을 골라 이동할 수 있습니다.

- **데스크탑마다 이름을 지정할 수 있습니다.** 매트릭스 칸의 메뉴에서 **데스크탑 이름 변경…**을 선택하세요. 같은 데스크탑을 여러 작업에서 사용하면 이름도 함께 바뀝니다. 순서를 바꾸거나 앱을 다시 켜고, 모니터를 재연결하거나 **현재 데스크탑으로 다시 구성…**을 실행해도 이름은 유지됩니다. **자동 이름 사용**을 선택하면 앱·창 콘텐츠로 제안하는 이름으로 돌아갑니다. 지정한 이름은 Sideby 안에 표시되며 Mission Control의 이름은 바뀌지 않습니다.
- **단축키를 누른 채 작업을 고르세요.** **⌥⇧Space**를 누르고 있으면 포인터 근처에 빠른 매트릭스가 나타납니다. 작업 열을 클릭하면 이동하며, 키를 누른 상태에서 다른 작업으로 다시 이동할 수도 있습니다. 단축키를 떼거나 Escape를 누르면 닫힙니다. **설정 → 입력**에서 단축키를 바꾸거나 끌 수 있습니다.
- **이동한 뒤에도 메뉴 매트릭스가 유지됩니다.** 메뉴창의 위치·크기·스크롤을 유지하며 전체 설정창이 앞으로 나오지 않습니다. macOS 27에서 전환 후 보이는 매트릭스가 클릭을 받지 못하던 문제도 수정했습니다.
- **매트릭스를 더 쉽게 읽고 조작할 수 있습니다.** 라이트·다크 모드에서 현재 작업, 배정된 데스크탑, 드래그할 위치를 구분하기 쉽도록 다듬었습니다. 이동 버튼은 작업 이름과 왼쪽 정렬하고, 현재 작업 표시는 별도로 배치했습니다. 메뉴·설정·온보딩의 배경과 컨트롤도 일관되게 정리했습니다.
- **다시 구성한 직후 실행을 취소할 수 있습니다.** 완료 안내 안에 **실행 취소**를 제공합니다. 평소 화면에 계속 보이던 이전 구성 복원 버튼은 제거했습니다.

기존 작업 배정·이름·입력 설정은 유지됩니다. 직접 지정한 데스크탑 이름과 빠른 매트릭스 설정은 Mac에 로컬로 저장합니다. 작업 이름과 데스크탑 이름은 별개이므로, 데스크탑 이름을 바꿔도 기존 작업 이름이 자동으로 바뀌지는 않습니다. 화면 하나에서도 사용할 수 있으며 macOS Space를 생성·삭제하거나 이름을 바꾸지는 않습니다.
