# Sideby 0.11.0

## English

Back to your work, in one action. Keep your development and review desktops together, arrange them directly from the menu bar, and use the same shortcut to go back and forth.

- **The workspace matrix is right in the menu.** Select displays, rename workspaces, refresh desktops, and edit assignments without opening the full Settings window. The redesigned Settings window includes the same matrix, with clearer light and dark appearances.
- **Return with Option + Shift + Tab.** Switch to the previous workspace, then use the same shortcut again to come back. Successful workspace visits determine the return destination.
- **Move, swap, or share desktops.** Drag within a display row to move an assignment into an empty cell or swap occupied cells. Option-drag into an empty cell to use the same desktop in another workspace. Drag a display’s name or up/down icon to reorder rows, or use the assignment menus with the keyboard.
- **Keep working as your display setup changes.** Single-display setups are supported, display selections are remembered across reconnects, and the menu can refresh changed desktop arrangements. Content labels are suggested for each display’s desktops, including desktops you are not currently viewing, when app/window metadata is available. Names you edit yourself are preserved.
- **Start with a real round trip.** The updated setup guide helps you choose displays, name two workspaces, check their content, and visit another workspace before returning. It explains single-display use and hands you back to the menu when you finish.
- **Clearer recovery and window behavior.** Incomplete moves can retry only the displays still pending. Settings opens in front when requested, and interactive controls provide pointer feedback.

The English and Korean READMEs now include current screenshots and a refreshed, explicitly labeled simulated demo. Sideby switches existing macOS desktops; it does not reopen documents or restore window contents and positions.

Requires macOS 14 or later. Existing workspace names and settings are retained when updating.

## 한국어

하던 작업으로 한 번에 돌아오세요. 개발과 리뷰에 쓰는 데스크탑을 작업별로 묶고, 메뉴에서 바로 배정을 바꾸며, 같은 단축키로 두 작업을 오갈 수 있습니다.

- **메뉴를 열면 작업 매트릭스가 바로 보입니다.** 전체 설정 창에 들어가지 않고 화면 선택, 작업 이름 수정, 데스크탑 새로고침과 배정 편집을 할 수 있습니다. 새 설정 창에도 같은 매트릭스를 제공하고 라이트·다크 모드의 구분을 개선했습니다.
- **Option + Shift + Tab으로 직전 작업에 돌아갑니다.** 같은 단축키를 다시 누르면 방금 작업으로 돌아옵니다. 이동에 성공한 작업을 기준으로 복귀 대상을 정합니다.
- **데스크탑 배정을 이동·맞교환·복사할 수 있습니다.** 같은 디스플레이 행의 빈 칸으로 드래그하면 배정을 옮기고, 채워진 칸으로 드래그하면 맞바꿉니다. Option을 누른 채 빈 칸으로 드래그하면 원래 배정을 유지하며 다른 작업에서도 함께 사용합니다. 화면 이름과 상하 아이콘으로 행 순서를 바꾸거나, 키보드로 배정 메뉴를 사용할 수도 있습니다.
- **화면 구성이 바뀌어도 작업을 이어갑니다.** 화면 하나에서도 사용할 수 있고, 모니터를 다시 연결했을 때 이전 선택을 기억합니다. 메뉴에서 바뀐 데스크탑 구성을 새로고침할 수 있으며, 가능한 경우 지금 보고 있지 않은 데스크탑까지 화면별 콘텐츠 이름을 제안합니다. 직접 수정한 작업 이름은 유지합니다.
- **첫 사용 안내에서 직접 두 작업을 왕복합니다.** 함께 움직일 화면을 고르고, 두 작업의 이름과 콘텐츠를 확인한 뒤 다른 작업에 갔다가 돌아옵니다. 화면 하나로 사용하는 방법을 설명하고, 완료 후 메뉴에서 계속 사용할 수 있도록 안내합니다.
- **실패 복구와 창 동작을 개선했습니다.** 일부 화면이 이동하지 못하면 아직 목적지에 도착하지 않은 화면만 다시 시도할 수 있습니다. 설정을 열면 창을 앞으로 가져오고, 조작할 수 있는 요소에는 포인터 반응을 제공합니다.

한국어·영어 README의 스크린샷과 데모도 현재 UI에 맞춰 갱신했습니다. 데모의 화면 전환은 시뮬레이션으로 표시합니다. Sideby는 기존 macOS 데스크탑을 전환하며, 앱과 문서를 다시 열거나 창 내용·위치를 복원하지는 않습니다.

macOS 14 이상이 필요합니다. 업데이트해도 기존 작업 이름과 설정을 유지합니다.
