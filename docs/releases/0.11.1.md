# Sideby 0.11.1

## English

Keep workspaces connected to the desktops you expect, and start over in the current desktop order when you need to.

- **Switching works again on macOS 27.** Updated Dock gesture events fix desktop-switch requests that did not move the screen, including on a single display. Reduced swipe travel makes transitions less distracting; nonadjacent moves still use the intervening desktops internally.
- **Desktop changes update automatically.** Surviving desktops keep their workspace assignments when reordered, including across an app restart. New and removed desktops are reconciled while the matrix is open and before switching. Edited names and shared-desktop assignments are preserved during routine updates.
- **One clear way to start over.** Both the menu and Workspaces & Displays settings now offer **Rebuild from current desktops…** instead of Refresh. Confirm the workspace count, then replace the selected displays’ names and assignments in current desktop order. Available desktop content supplies fresh names, with desktop numbers as a fallback. Other displays’ assignments are kept separately.
- **Restore the previous setup.** The last configuration before a rebuild is saved locally. Restore follows the same desktops if their order has changed. If a required desktop is missing, the backup is kept for later.
- **Shortcut numbers match visible workspaces.** Workspaces belonging only to disconnected displays no longer occupy positions in the menu’s number shortcuts.

Updating keeps existing names and settings. If assignments from an older version are already wrong, rebuild once: older versions did not retain enough desktop identity information to reconstruct a past arrangement. Minimal desktop identity bookmarks and the previous setup are now saved locally on your Mac; numeric runtime Space handles are not persisted.

The English and Korean README screenshots and simulated demo have been updated. Requires macOS 14 or later.

## 한국어

작업이 원래 데스크탑을 계속 가리키도록 연결을 개선하고, 필요할 때 현재 데스크탑 순서로 다시 시작할 수 있도록 정리했습니다.

- **macOS 27에서 데스크탑 전환을 수정했습니다.** 이동을 요청해도 화면이 바뀌지 않던 문제를 Dock 제스처 이벤트 수정으로 해결했습니다. 화면 하나인 환경에도 적용됩니다. 스와이프 이동 폭을 줄여 전환 효과를 완화했으며, 떨어진 데스크탑으로 갈 때는 내부적으로 중간 데스크탑을 거칩니다.
- **데스크탑 변경을 자동으로 반영합니다.** 순서를 바꾸거나 앱을 다시 켜도 기존 작업은 같은 데스크탑을 따라갑니다. 매트릭스가 열려 있을 때와 이동 직전에 추가·삭제된 데스크탑을 확인합니다. 평소 자동 반영 중에는 직접 수정한 이름과 여러 작업에서 함께 쓰는 배정을 유지합니다.
- **새로 시작하는 동작을 하나로 정리했습니다.** 메뉴와 ‘작업과 화면’ 설정의 새로고침을 **현재 데스크탑으로 다시 구성…**으로 바꿨습니다. 생성할 작업 수를 확인한 뒤 선택한 화면의 이름과 배정을 현재 순서로 새로 만듭니다. 콘텐츠를 읽을 수 있으면 이름으로 제안하고, 없으면 데스크탑 번호를 사용합니다. 다른 화면의 배정은 따로 보관합니다.
- **이전 구성으로 되돌릴 수 있습니다.** 마지막 재구성 직전 상태를 로컬에 보관합니다. 순서가 바뀌어도 같은 데스크탑을 찾아 복원하며, 필요한 데스크탑이 없으면 이전 구성을 계속 보관합니다.
- **보이는 작업과 단축키 순번을 맞췄습니다.** 연결되지 않은 화면에만 배정된 작업이 메뉴의 숫자 단축키 순번을 차지하지 않도록 수정했습니다.

업데이트해도 기존 이름과 설정은 유지합니다. 이전 버전에서 이미 배정이 어긋났다면 ‘다시 구성’으로 한 번 정리해 주세요. 과거 버전에는 이전 연결 관계를 복원할 식별 기록이 없었습니다. 이번 버전부터 최소 데스크탑 식별 정보와 이전 구성을 Mac에 로컬로 저장하며, 실행 중 사용하는 숫자 Space ID는 저장하지 않습니다.

한국어·영어 README의 스크린샷과 시뮬레이션 데모도 갱신했습니다. macOS 14 이상이 필요합니다.
