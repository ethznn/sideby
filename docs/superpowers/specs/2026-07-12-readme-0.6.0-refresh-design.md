# README 0.6.0 Refresh Design

Date: 2026-07-12

## Goal

Make the English and Korean READMEs accurately represent the Sideby 0.6.0
menu-bar experience without turning the README into a detailed changelog.

## Preview Images

- Replace `docs/images/sideby-context-capture.png` with a current 0.6.0
  screenshot of the compact floating menu.
- The screenshot must show the current Context matrix, including the
  directional Context/Display labels and naturally sized header.
- The screenshot must not show the removed last-switch row or the old tall
  Context header.
- Keep `docs/images/sideby-swipe-onboarding.png` because the onboarding gesture
  screen did not change in 0.6.0.
- Keep the existing image paths and README widths so external links and layout
  remain stable.
- Update the Context screenshot alt text in both READMEs to describe the 0.6.0
  menu and Context matrix rather than Context Capture alone.

## English README Copy

- Update `Status` from 0.5.0 to 0.6.0 and summarize the release around three
  user-visible changes: menu-bar-only presentation, authoritative Context
  activation while Sideby is off, and the clearer space-efficient matrix.
- Update the first `Features` bullet to state that Sideby stays in the menu bar
  and does not remain in the Dock.
- Extend the Context matrix bullet with directional axes and natural header
  sizing.
- Extend direct Context activation to state that activation is unavailable
  while Sideby is off, switching, or capturing.
- Add a `Quick Start` sentence telling users to open Sideby from the menu bar;
  no Dock icon is expected.

## Korean README Copy

Apply the same facts and scope as the English README using natural Korean UI
terms. Keep product labels such as Sideby, Context, Space, Go/이동, and Dock
consistent with the app and existing README vocabulary.

## Non-Goals

- Do not rewrite the product introduction, architecture, privacy, permission,
  contribution, security, or license sections.
- Do not add release badges, animated GIFs, additional screenshots, or a
  0.6.0 changelog section.
- Do not alter the unchanged onboarding screenshot.
- Do not include Direct Space Jump research or experimental DevApp behavior.

## Validation

- Confirm both README files reference existing image paths.
- Confirm neither README still describes 0.5.0 as the current status.
- Confirm the English and Korean feature claims remain semantically aligned.
- Inspect the replacement screenshot at full resolution for current UI,
  readable text, tight cropping, and absence of private or diagnostic data.
- Run `git diff --check` and verify only README-refresh files are staged.
